# Adeus Canelite: página de vendas

Landing page do programa **Adeus Canelite**, para o mercado português.

Site estático, sem build. Publicado por GitHub Pages a partir da branch `main`, raiz.

| Ficheiro | O que é |
|---|---|
| `index.html` | a página de vendas |
| `termos.html` | termos e condições |
| `privacidade.html` | política de privacidade (RGPD) |
| `img/` | as fotografias da página |
| `og.jpg` | imagem de partilha |

**A fábrica é outro repositório.** Doutrina, decisões, auditorias de copy e o plano da oferta
vivem no repositório da operação, não aqui. Este repo só publica.
